# ClipperAI

**A local, private, agentic AI brainstorming assistant** powered by FLAN-T5 + LangGraph.

### Features
- Persistent memory (SQLite + ChromaDB)
- Document upload & intelligent clipping (RAG)
- Safety disclaimers on every response
- Fully local & offline capable
- Basic multi-step agent planning

**⚠️ This is a brainstorming tool only. Not professional advice.**
